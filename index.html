House Price Prediction using Deep Learning

Academic project • MIS373

20,000observations
8neural models
0.8445best R²
0.9193best correlation

Overview

Overview
House price prediction
The project analysed approximately 20,000 observations to understand which features influence property prices.
Core finding
Size and quality matter
The report found that sqft_living and grade have the strongest positive relationships with price.

Data Exploration & Pre-processing

Data quality
No missing values
The dataset contained no missing values, and the date variable was removed because it was not necessary for model input.
Correlation
sqft_living 0.70
grade also showed a strong correlation with price at 0.67, while zipcode (-0.04) and long (0.01) were close to zero.
Outliers
Top 1% removed
A 99th percentile threshold of about $1,950,000 was used to remove extreme price values and reduce skewness.
Final dataset
19,801 rows
After removing nearly 200 rows, the refined dataset contained 19,801 observations.

Model Pipeline

1
Train / validation split
The processed data was split 70/30 for training and validation.
2
Min-Max normalisation
All input variables were scaled to the range 0–1.
3
Linear baseline
Multi-linear regression was used as the baseline before neural networks.
4
8 neural models
The report compared 8 neural network configurations, from one-layer to four-layer models.

Model Comparison

Best model
NN4
NN4 achieved the best overall performance with R² = 0.8445 and correlation = 0.9193.
Worst models
NN2 & NN5
NN2 and NN5 performed the worst, with negative R² values of -3.2948 and -3.2201.
Generalisation
3-layer balance
The report concluded that the three-layer network balanced accuracy and generalisation best.
Risk
Luxury bias
Removing high-price outliers improved stability but limited the model's ability to predict luxury properties.

Waste Image Classification (CNN)

Academic project • MIS373

6waste classes
69.53%best test accuracy
0.631Cohen's Kappa

Overview

Overview
Image classification for waste sorting
The project analysed 2,864 waste images across six categories to compare ANN and CNN models.
Objective
Identify the best architecture
The report evaluated which model design works best for waste image classification.

Data Exploration & Pre-processing

Classes
6 categories
Cardboard, Glass, Metal, Paper, Plastic, Vegetation.
Resize
100 × 100 pixels
All images were resized to a uniform shape for batch processing.
Encoding
Label + one-hot
Labels were converted to integers and then one-hot encoded for softmax output.
Split
70 / 30
The train-test split produced 2,004 training images and 860 test images.

Model Development & Comparison

ANNs vs CNNs
4 vs 6 models
Four ANN models and six CNN models were evaluated with varying architectures.
Best model
CNN4
CNN4 achieved the best test accuracy at 69.53% and the highest Cohen's Kappa at 0.631.
Overfitting
ANN4, CNN3, CNN5
These models learned on training data but failed to generalise well on test data.
Best class
Vegetation
Vegetation had the best F1-score at 0.94 in the CNN4 classification report.
